# Interviu AI Version 1

Interviu AI is a premium SaaS platform that helps students prepare for interviews professionally.

## Project Setup

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation
1. Clone the repository or navigate to the project directory.
2. Run `npm install` to install dependencies.

### Development Server
Run `npm run dev` to start the Vite development server.

### Build
Run `npm run build` to create a production-ready bundle.

## Tech Stack
- React
- Vite
- React Router DOM
- Tailwind CSS v4
- Framer Motion
- Axios
- TanStack Query
- React Hook Form
- Lucide React
